# CNN-Image-Classification
Beginner-friendly Convolutional Neural Network (CNN) implementation using Python, NumPy, OpenCV, Matplotlib and TensorFlow/Keras. Covers image preprocessing, convolution, filters, feature maps, ReLU, max pooling, flattening, and binary image classification.

# CNN From Scratch

## Project Overview
This project demonstrates the fundamentals of Convolutional Neural Networks (CNNs) using Python and TensorFlow/Keras.

## Topics Covered
1. Image loading using OpenCV
2. Image preprocessing
3. RGB and grayscale images
4. Image resizing (224 × 224)
5. Image normalization
6. NumPy arrays and image dimensions
7. Convolution operation
8. Kernels and filters
9. Feature maps
10. ReLU activation
11. Max Pooling
12. Flatten layer
13. Dense layers
14. Binary image classification
15. CNN model compilation and training

## Technologies Used
- Python
- NumPy
- OpenCV
- Matplotlib
- TensorFlow
- Keras
- Google Colab

## Model Architecture
- Input Layer: 224 × 224 × 3
- Conv2D: 32 filters
- MaxPooling2D
- Conv2D: 64 filters
- MaxPooling2D
- Flatten
- Dense: 128 neurons
- Output: 1 neuron with Sigmoid activation

## Learning Objective
To understand how CNNs process images, extract features and perform binary classification.
